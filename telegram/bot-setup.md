# Как открыть игру из бота в Telegram

Игра открывается внутри Telegram как Mini App — по кнопке в чате с ботом. Это веб-приложение, размещённое на HTTPS; отдельный сервер бота для текущей версии не требуется.

## Что нужно
- Telegram-бот, созданный через официальный BotFather.
- Развёрнутый фронтенд на публичном HTTPS-домене.
- Публичный URL приложения.

## Шаги
1. Если бот ещё не создан, откройте @BotFather и создайте его командой `/newbot`.
2. Соберите проект из его корневой папки командой `npm run build`.
3. Создайте GitHub-репозиторий и отправьте в него проект в ветку `main`.
4. В репозитории откройте **Settings → Pages** и в поле **Build and deployment → Source** выберите **GitHub Actions**. Файл `.github/workflows/deploy.yml` соберёт приложение и опубликует `dist/` на HTTPS при каждом обновлении ветки `main`.
5. Дождитесь успешного запуска workflow. Скопируйте опубликованный HTTPS URL со страницы **Settings → Pages**.
6. В @BotFather запустите `/setmenubutton`, выберите бота, задайте надпись кнопки (например, «Играть») и укажите HTTPS URL.
7. Дополнительно можно настроить Main Mini App бота через `/mybots` → выберите бота → **Bot Settings → Configure Mini App**. Тогда на странице профиля бота появится кнопка запуска приложения.
8. Откройте чат с ботом на iPhone и Android и нажмите «Играть». Проверьте карточки, настройки и воспроизведение звука после нажатия.

У Mini App должен быть доступный HTTPS URL до настройки кнопок. Локальный `localhost` с телефона Telegram открыть не сможет.

## Безопасность
- Для текущего MVP backend и bot token во фронтенде не нужны. Настройку кнопки можно выполнить в @BotFather.
- Не вставляйте токен бота в `VITE_*` переменные: они попадут в клиентскую сборку.
- Не отправляйте `Telegram.WebApp.initData` на сторонние сервисы.
- Если в будущем добавится backend-авторизация, `initData` нужно проверять на сервере по официальной документации Telegram.
