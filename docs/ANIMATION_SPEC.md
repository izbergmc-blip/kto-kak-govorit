# Спецификация анимаций

## Общие правила
- Длительность реакции примерно 0.8–1.5 секунды; без бесконечного движения и мигания.
- Анимация запускается при нажатии, не должна блокировать повторное нажатие.
- Предусмотреть `prefers-reduced-motion`; при reduced motion оставить лёгкое изменение масштаба/подсветку.
- На первом MVP допустимы CSS transforms вместо Lottie, если это надёжнее и легче.

## Движения
- Корова: мягкий кивок головы, одно моргание.
- Кошка: моргание, лёгкое движение хвоста.
- Собака: короткое виляние хвостом и лёгкий подпрыг.
- Утка: один взмах крыльями.
- Лошадь: поднять и опустить переднюю ногу.
- Овечка: маленький мягкий подпрыг.
- Свинка: движение пятачка/ушей.
- Петушок: один взмах крыльями и подъём головы.
- Лягушка: короткий подпрыг.
- Лев: поднять голову и открыть рот без устрашающего оскала.

## Доступность
Анимация не должна быть единственным способом сообщить состояние; название и звукоподражание остаются видимыми.
