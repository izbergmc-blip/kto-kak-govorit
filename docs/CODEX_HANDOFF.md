# Инструкция передачи проекта в Codex

1. Распакуйте архив в отдельную папку.
2. Откройте в Codex именно папку `kto_kak_govorit_v1` (корень, где лежит `package.json`).
3. Попросите Codex сначала прочитать `CODEX_MASTER_PROMPT.md`, `README.md`, все файлы `docs/`, `data/animals.json` и проверить текущий код.
4. Попросите выполнить команды `npm install`, `npm run test`, `npm run build`; исправить ошибки, не удаляя требования безопасности и UX.
5. После локальной проверки добавьте лицензированные аудиофайлы и финальные изображения в предусмотренные каталоги.
6. Перед публикацией пройдите `docs/RELEASE_CHECKLIST.md` и `telegram/bot-setup.md`.

Важно: текущие иллюстрации — JPG-черновики с белым фоном. Аудиофайлы намеренно не подделаны и пока отсутствуют. Приложение должно запускаться без них, но полноценный звуковой сценарий заработает после добавления записей.
