# Сценарий записи аудио

## 10 голосов животных
Записывать короткие, узнаваемые, не пугающие звуки. Предпочтительно 1–3 секунды на файл, без музыки, речи людей и резкого фонового шума.

| ID | Животное | Что записать | Имя файла |
|---|---|---|---|
| cow | Корова | Натуральное мычание | `cow.mp3` |
| cat | Кошка | Натуральное мяуканье | `cat.mp3` |
| dog | Собака | Один-два спокойных лая | `dog.mp3` |
| duck | Утка | Натуральное кряканье | `duck.mp3` |
| horse | Лошадь | Ржание | `horse.mp3` |
| sheep | Овечка | Блеяние | `sheep.mp3` |
| pig | Свинка | Хрюканье | `pig.mp3` |
| rooster | Петушок | Кукареканье | `rooster.mp3` |
| frog | Лягушка | Кваканье | `frog.mp3` |
| lion | Лев | Рык льва, не чрезмерно громкий/агрессивный | `lion.mp3` |

## 10 реплик диктора
Один и тот же спокойный, доброжелательный голос, без фоновой музыки и театрального крика. Чёткая артикуляция, естественный темп, короткая пауза между названием и звукоподражанием.

1. «Корова! Му-у-у!»
2. «Кошка! Мяу-мяу!»
3. «Собака! Гав-гав!»
4. «Утка! Кря-кря!»
5. «Лошадь! И-го-го!»
6. «Овечка! Бе-е-е!»
7. «Свинка! Хрю-хрю!»
8. «Петушок! Ку-ка-ре-ку!»
9. «Лягушка! Ква-ква!»
10. «Лев! Р-р-р!»

## Технические параметры
- Формат: MP3, mono допустимо, 44.1 kHz, 96–128 kbps достаточно для коротких голосов.
- Пиковый уровень без клиппинга; выровнять воспринимаемую громкость всех файлов.
- Оставить короткие естественные паузы, удалить длинную тишину в начале/конце.
- Проверить на динамике обычного смартфона.
- Не использовать TTS для имитации реального животного.
- Хранить происхождение и лицензию каждого файла в `AUDIO_LICENSES.csv`.
