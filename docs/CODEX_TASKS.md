# План задач Codex

## Задача 1 — аудит и запуск
- Прочитать все документы.
- Проверить `package.json`, TypeScript и структуру.
- Выполнить `npm install`, `npm run test`, `npm run build`.
- Исправить ошибки до зелёной сборки.

## Задача 2 — интерфейс
- Проверить главный экран на 320–430 px ширины и малой высоте.
- Проверить, что 10 карточек доступны и не становятся слишком мелкими.
- Проверить fallback битой картинки.
- Проверить настройки, закрытие модальных окон и localStorage.
- Проверить Telegram WebView safe areas и браузерный fallback.

## Задача 3 — звук
- Проверить сценарии с обоими каналами, каждым каналом отдельно и обоими выключенными.
- Проверить отмену текущего звука новым нажатием.
- Проверить `play()` rejection, `error`, `pagehide`, `visibilitychange`.
- Отсутствующие файлы не заменять тишиной или синтезированной речью.

## Задача 4 — подготовка релиза
- Подтвердить замену черновых JPG на утверждённые production-иллюстрации или явно оставить пометку о черновом статусе.
- Проверить аудиолицензии по `AUDIO_LICENSES.csv`.
- Обновить README и release checklist.
- Не публиковать приложение автоматически и не придумывать URL.
