# Кто как говорит? — игра внутри Telegram

«Кто как говорит?» — мобильная игра для малышей 18–24 месяцев, которая открывается внутри Telegram по кнопке бота. Технически это Telegram Mini App: Telegram показывает веб-приложение во встроенном окне, а тот же адрес можно открыть в обычном браузере. Ребёнок выбирает одно из десяти животных; карточка реагирует, затем должны воспроизводиться настоящий звук животного и короткая русская реплика диктора.

## Что уже есть в репозитории
- React + TypeScript + Vite starter.
- Главный экран с 10 животными, карточками и адаптивной сеткой.
- Настройки с независимыми переключателями двух аудиоканалов.
- Локальное сохранение настроек.
- Единый аудиоконтроллер: отмена предыдущей последовательности, без очереди, остановка при уходе в background.
- Безопасная инициализация Telegram WebApp SDK, браузерный fallback.
- CSS-реакции карточек и поддержка `prefers-reduced-motion`.
- Спецификации, сценарий записи звуков, реестр лицензий, чек-лист релиза и мастер-промпт Codex.

## Важный статус медиа
Для всех десяти животных добавлены прозрачные PNG. Карточки показываются по одной на весь экран и перелистываются горизонтальным жестом. Звуковые файлы намеренно не подделаны и пока отсутствуют. До добавления лицензированных записей приложение демонстрирует интерфейс и визуальные реакции, но полноценный звуковой сценарий не будет работать.

## Запуск локально
Требуется Node.js LTS и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`). Для проверки на телефоне используйте адрес локальной сети, выведенный Vite, либо временный HTTPS-туннель; Telegram Mini App в продакшене требует публичный HTTPS URL.

## Проверки

```bash
npm run test
npm run build
npm run preview
```

## Добавление аудио
Положите настоящие записи сюда:

```text
public/assets/audio/animals/{id}.mp3
public/assets/audio/voices/{id}.mp3
```

ID: `cow`, `cat`, `dog`, `duck`, `horse`, `sheep`, `pig`, `rooster`, `frog`, `lion`. Сценарий и требования — `docs/AUDIO_RECORDING_SCRIPT.md`. Зафиксируйте источник и права в `AUDIO_LICENSES.csv`.

## Запуск игры из Telegram на телефоне
1. Соберите приложение командой `npm run build`.
2. Создайте GitHub-репозиторий и отправьте в него содержимое этой папки в ветку `main`.
3. В репозитории откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника публикации. Workflow автоматически соберёт приложение и опубликует папку `dist/` на HTTPS.
4. После успешной публикации скопируйте адрес сайта из **Settings → Pages**.
5. В @BotFather свяжите этот адрес с ботом как Mini App и задайте кнопку меню «Играть» командой `/setmenubutton`.
6. Откройте чат с ботом на телефоне и нажмите кнопку «Играть».

Игра откроется внутри Telegram. Для этой версии сервер бота и Bot API token во фронтенде не нужны. Подробная инструкция: `telegram/bot-setup.md`.

## Что открыть в Codex
Откройте корень этой папки и отправьте содержимое `CODEX_MASTER_PROMPT.md` как основное задание. Дополнительная инструкция — `docs/CODEX_HANDOFF.md`.
