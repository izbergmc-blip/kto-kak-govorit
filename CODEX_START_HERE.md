# Начать работу в Codex

**Открой в Codex корневую папку `kto_kak_govorit_v1` — ту, где лежат `package.json` и `CODEX_MASTER_PROMPT.md`.**

Затем вставь в Codex весь текст файла `CODEX_MASTER_PROMPT.md`.

Codex должен сначала проверить проект, затем выполнить:

```bash
npm install
npm run test
npm run build
npm run dev
```

Исправить ошибки и показать результаты. Не переходить к публикации, пока не будут проверены тесты и сборка.

## Что уже внутри
- готовый стартовый React + TypeScript + Vite проект;
- главный экран, 10 карточек животных, настройки;
- управление аудио с отменой предыдущего воспроизведения;
- тесты ключевых частей;
- Telegram WebApp integration без обязательной авторизации;
- спецификации, аудиосценарий, чек-лист, инструкции BotFather;
- 10 временных изображений животных и визуальные референсы.

## Что ещё нужно добавить до полноценного звукового релиза
- 10 лицензированных натуральных звуков животных;
